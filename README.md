# Facts Germany

Daten-Shorts über Deutschland ("Deutschland in Zahlen") für TikTok.

- `videos/` – fertige Videos (9:16, MP4), werden von Metricool über die öffentliche Raw-URL abgeholt
- `covers/` – Titelbilder
- `renderer/` – Python-Renderer (Pillow + ffmpeg). Neue Videos: Szenen in `specs.py` anlegen, dann `python3 renderer/run_dv.py`
